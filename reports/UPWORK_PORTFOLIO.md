# Upwork portfolio text

## Title
Ecommerce Sales Analysis, SQL & Customer Retention Dashboard

## Role
Data Analyst

## Description
I analysed 541,909 historical retail transaction rows to understand sales, credit activity and repeat purchasing. I built a reproducible Python cleaning pipeline, a SQLite database, SQL analyses and an interactive dashboard. The analysis identified £9.75M in net sales and a 65.6% repeat-purchase share among identified customers. Deliverables include customer segments, cohort retention, product rankings and practical recommendations. Independent portfolio project using the public UCI Online Retail dataset.
